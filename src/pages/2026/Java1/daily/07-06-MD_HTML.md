## 마크다운 언어(Markdown)

개발자의 글쓰기에서 제일 많이 쓰는 언어

1. 제목 쓰기 

**HTML 코드**

```html
<h1>    #
<h2>    ##
<h3>    ###
```

**마크다운 코드**

```markdown
# 제목 1
## 제목 2
### 제목 3
```

2. 글자 강조

**HTML**

```html
<strong></strong>
<b></b>
```

```markdown
**굵은 글씨**
*이탤릭체 글씨*
```

3. 목록 만들기

**HTML**

```html
<ul>
    <li>아이템 1</li>
    <li>아이템 2</li>
</ul>

<ol>
    <li>목록 1</li>
    <li>목록 2</li>
</ol>
```

**마크다운**

```markdown
* 
* 

1. 
2. 
3. 
```

4. 링크 달기

**HTML**

```html
<a href="링크주소" target="">링크</a>
```

**마크다운**

```markdown
[링크](링크주소)
```

| :--- | :--- | :--- |

| **2. 글자 강조** <br> (`*`) | `**이 글자는 굵게**`<br>`*이 글자는 기울임*` | 단어 양옆을 `**`로 감싸면 텍스트가 **굵게(Bold)** 변환되고, `*` 하나로 감싸면 *기울임(Italic)*체로 출력됩니다. |

## 웹의 진짜 언어 알아보기: 마크다운에서 HTML로!

**개념 설명**

HTML은 항상 열어주는 태그 `<태그명>`과 닫아주는 태그 `</태그명>`가 한 쌍으로 동작합니다. 닫는 태그에는 반드시 슬래시(`/`)가 들어갑니다.

* 마크다운 `#` → HTML `<h1>` ~ `<h6>` (Heading: 제목)
* 마크다운 `**` → HTML `<strong>` (Strong: 굵게 강조)

예제

```html
<h1>나의 웹페이지</h1>
<p>이곳에 오신 것을 <strong>환영합니다</strong>!</p>
```

HTML에서 목록(List)을 만들 때는 두 가지 태그가 조립되어 사용됩니다. 마크다운의 `-` 기호 하나가 HTML에서는 두 개의 태그로 나뉩니다.

* `<ul>` (Unordered List): "지금부터 순서 없는 점(•) 목록을 시작하겠습니다"라는 뜻의 **부모 태그**입니다.
* `<li>` (List Item): 목록에 들어갈 각각의 항목을 나타내는 **자식 태그**입니다.

예제

```html
<ul>
    <li>사과</li>
    <li>포도</li>
    <li>바나나</li>
</ul>
```
