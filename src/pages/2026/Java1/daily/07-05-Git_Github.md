## 깃(Git)

![git](../../../../assets/images/20270707_02_git.PNG)

깃은 소스코드 타임머신이다. 

사진 찍듯이 소스코드를 저장해서 언제든지 그때의 상태로 돌아갈 수 있다.

깃 리포지토리: 깃의 저장소입니다.

프로젝트를 저장하는 공간

깃 프로필(Profile)

## Git 명령어

* 커밋(commit): 상태 저장 (현재 코드 사진찍기)
* 브랜치(branch): 또 다른 작업 공간 만들기
* 푸시(push): 업로드(깃허브에 업로드)
* 풀(pull): 다운로드(깃허브에서 다운로드)
* 체크아웃(checkout): 그때의 시점으로 이동하기
