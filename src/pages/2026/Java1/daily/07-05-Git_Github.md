## 리포지토리(Repository) 

깃 리포지토리: 깃의 저장소입니다.

프로젝트를 저장하는 공간

깃 프로필(Profile)

## Git 명령어

* 커밋(commit): 상태 저장 (현재 코드 사진찍기)
* 브랜치(branch): 또 다른 작업 공간 만들기
* 푸시(push): 업로드(깃허브에 업로드)
* 풀(pull): 다운로드(깃허브에서 다운로드)
* 체크아웃(checkout): 그때의 시점으로 이동하기

## 마크다운 언어(Markdown)

개발자의 글쓰기에서 제일 많이 쓰는 언어

1. 제목 쓰기 

**HTML 코드**

```html
<h1>    #
<h2>    ##
<h3>    ###
```

**마크다운 코드**

```markdown
# 제목 1
## 제목 2
### 제목 3
```

2. 글자 강조

**HTML**

```html
<strong></strong>
<b></b>
```

```markdown
**굵은 글씨**
*이탤릭체 글씨*
```

3. 목록 만들기

**HTML**

```html
<ul>
    <li>아이템 1</li>
    <li>아이템 2</li>
</ul>

<ol>
    <li>목록 1</li>
    <li>목록 2</li>
</ol>
```

**마크다운**

```markdown
* 
* 

1. 
2. 
3. 
```

4. 링크 달기

**HTML**

```html
<a href="링크주소" target="">링크</a>
```

**마크다운**

```markdown
[링크](링크주소)
```
